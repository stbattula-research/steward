# Playbook: Pay a bill (example: edit or remove)

Write each playbook the way you'd explain the task to an assistant sitting next to you.
The agent reads the matching playbook before doing that kind of task.

1. Open the biller's website and log in with saved login `utility` (see vault.py).
2. Go to Billing > Pay now.
3. Use the saved bank account already on file. Never add a new card.
4. Before clicking Pay: request approval with the amount and due date.
5. After paying, screenshot the confirmation and send it to me.
